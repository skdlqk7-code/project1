# 동네 워밍업 & 라이브 미니룸 (React + Vite)

동네 기반 소모임(마미모임, 동네루틴, 원데이 클래스)과 싸이월드 미니룸 감성의 2D 실시간 워밍업 소통 웹앱입니다.

---

## 🛠 기술 스택
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React

---

## 🚀 로컬 실행 방법

터미널에서 아래 명령어를 실행하면 즉시 개발 서버가 열립니다:

```bash
# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

---

## 📁 프로젝트 구조

```text
src/
├── constants/
│   └── data.js              # 방 목록, 온보딩 질문, 아바타 아이템 등 정적 데이터
├── components/
│   ├── Onboarding.jsx       # 1~3단계 관심사 및 동네 온보딩
│   ├── LiveRoom.jsx         # 5초 카운트다운, AI 호스트 루나(20초 턴), 미니룸 2D 스테이지, 소통 컨트롤
│   ├── HomeFeed.jsx         # 모임 피드, 카테고리 필터, 원데이 클래스 큐레이션
│   ├── AvatarStore.jsx      # 내 아바타 꾸미기 및 캐시 스토어
│   ├── MySettings.jsx       # 마이 설정 (온보딩 재설정)
│   ├── RoomDetailModal.jsx  # 모임 상세 팝업
│   └── CreateRoomModal.jsx  # 새 번개방/모임 개설 모달
├── App.jsx                  # 전역 라우팅 및 탭 네비게이션
├── main.jsx                 # 엔트리 포인트
└── index.css                # Tailwind CSS 설정
```

---

## 💡 주요 개선 및 해결 사항
1. **단일 파일 컴포넌트 모듈화**: 630줄 거대 컴포넌트를 8개 독립 모듈로 분리하여 렌더링 성능 대폭 향상
2. **키보드 이벤트 리스너 누수 해결**: `useEffect` 의존성 배열 누락 버그 수정
3. **미니룸 드래그 인터랙션 보정**: 스테이지 외부로 마우스가 벗어나도 드래그가 끊기지 않도록 윈도우 포인터 이벤트 적용
4. **타이머 격리**: 5초 카운트다운과 20초 발언 턴이 다른 탭이나 전체 앱에 불필요한 리렌더링을 유발하지 않도록 격리
